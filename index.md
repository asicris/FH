## 🎯 Unidade Temática

### TRABALLANDO O HARDWARE DAS ESTACIÓNS DE TRABALLO

Esta unidade temática cobre os **coñecementos esenciais sobre os compoñentes de hardware** que conforman os equipos informáticos, con especial énfase na arquitectura das estacións de traballo. O estudiantado aprenderá a **identificar, medir, instalar e diagnosticar compoñentes de hardware**, así como a **comprender o funcionamento dos sistemas de alimentación e procesamento de datos**.

## 📖 Cómo Utilizar Este Módulo

### Para o Alumnado

1. **Comeza pola teoría** de cada tema para comprender os conceptos fundamentais.
2. **Estudia os exemplos** para ver casos reais de aplicación.
3. **Realiza os exercicios** para consolidar o aprendizaxe.
4. **Participa nas actividades de laboratorio** para gañar experiencia práctica.
5. **Usa as imaxes** como referencia visual durante o estudo.

### Para o Docente

- Os materiais están organizados por **niveles de dificultade** (teoría → exercicios → laboratorio).
- Cada tema inclúe **enlaces a recursos externos** (vídeos, ferramentas en liña).
- As actividades de laboratorio son **completamente prácticas** e requiren material real.
- Os exercicios **propoñen análises críticas** de casos reais do mercado.

---

## 🎓 Resultados de Aprendizaxe

Ao completar este módulo, o estudiantado será capaz de:

✅ Identificar e clasificar todos os compoñentes de hardware dunha estación de traballo.  
✅ Comprender o funcionamento dos sistemas de alimentación e as súas proteccións.  
✅ Seleccionar componentes axecuados segundo especificacións técnicas.  
✅ Montar unha estación de traballo seguindo protocolos de seguridade.  
✅ Medir e diagnosticar problemas utilizando ferramentas técnicas (multímetro, Power Supply Tester).  
✅ Analizar fichas técnicas de hardware real do mercado.
